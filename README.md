# Qubic Wallet troubleshooting guides

Twelve guides for the problems people actually report: sync stalls, missing balances, stuck
transactions, fees, addresses and a wallet that will not open.

Start with [Qubic Wallet not syncing](qubic-wallet-not-syncing.md), because most balance and
transaction symptoms trace back to it.

Each guide is ordered, not a checklist: read the first section, stop when it matches your case. A
successful-looking step that was skipped is usually why the next one fails.

Anything about the app itself, rather than a wallet problem, belongs in the
[desktop wallet repository](https://github.com/qubic-wallet/qubic-desktop-wallet).
